# Florin Testnet Bot

Мультиаккаунт-бот для тестнета [Florin](https://florin.so). Florin — лендинг-протокол для токенизированных акций на Robinhood Chain, официальный friendly fork Liquity V2: вносишь SPY в залог и минтишь стейблкоин FUSD.

*Multi-account automation for the Florin testnet (Liquity V2 fork on Robinhood Chain): faucet, Borrow, Multiply, Earn, Manage. Each account gets its own randomized behaviour profile.*

---

## Возможности

| Раздел сайта | Что делает бот |
|---|---|
| **Faucet** | клейм тестовых SPY раз в 2 ч (+ случайные 5–45 мин) через прокси аккаунта |
| **Borrow** | открытие позиции: SPY → FUSD (permit + GasCompZapper, как на сайте) |
| **Multiply** | позиция с плечом 1.5–3x в одну транзакцию (flash loan) |
| **Earn** | депозит FUSD в Stability Pool, вывод, клейм наград (FUSD yield + SPY с ликвидаций) |
| **Manage** | доливка или вывод залога, занять больше, погашение, смена ставки, смена плеча, закрытие |

**Защита от «одинаковых» аккаунтов**
- у каждого аккаунта свой профиль: число действий за сессию, веса действий, вилка ставки; часть второстепенных действий профиль может отключить
- случайные суммы, плечо, ставки и паузы между действиями
- у каждого аккаунта свой таймер по крану, многопоточный запуск вразнобой
- время сна (например, с 01:00 до 08:00), после сна аккаунты просыпаются вразнобой

**Надёжность**
- автозамена нерабочего прокси из пула: перед заменой проверяется свой интернет, так что при падении сети прокси не сжигаются
- все действия проверяются симуляцией перед отправкой; ошибки контрактов расшифровываются (`DebtBelowMin`, `ICRBelowMCR`, …)
- бот сам находит позиции, открытые руками на сайте (через логи TroveNFT)
- состояние хранится в `data/state.json`, после перезапуска бот продолжает с того же места
- подробные логи с ротацией

## Установка

```bash
git clone https://github.com/ggRonin/Florin.git
cd Florin
pip install -r requirements.txt
```

Нужен Python 3.10+.

## Настройка

1. Скопируй примеры и заполни своими данными:
   ```bash
   cp accounts.example.txt accounts.txt
   cp Proxy.example.txt Proxy.txt
   ```
   - `accounts.txt`: одна строка на аккаунт: `мнемоника или приватный ключ[,login:pass@host:port]`
   - `Proxy.txt`: запасные прокси `login:pass@host:port`, по одной на строку

   Оба файла в `.gitignore` и в репозиторий не попадают.

2. Основные настройки в [`settings.py`](settings.py):
   ```python
   THREADS = 5                        # сколько аккаунтов работает одновременно
   SLEEP_TIME = ("01:00", "08:00")    # бот ничего не делает в это время; None — без сна
   ```

3. Тонкая настройка (суммы, LTV, плечо, ставки, веса действий, тайминги) в [`config.py`](config.py).

## Запуск

```bash
python main.py run        # бесконечный фарм (Windows: start.bat, с автоперезапуском)
python main.py status     # балансы и позиции всех аккаунтов
python main.py faucet     # только кран
python main.py once       # одна сессия на каждый аккаунт

# выборочно
python main.py once --only 1-5,8
python main.py once --only 3 --action open_multiply --n 1
```

Действия для `--action`: `open_borrow`, `open_multiply`, `sp_deposit`, `sp_withdraw`, `sp_claim`, `add_coll`, `withdraw_coll`, `borrow_more`, `repay`, `set_rate`, `lever`, `close_borrow`, `close_multiply`.

## Стратегия по умолчанию

Команда Florin публично меряет успех объёмом выпущенного FUSD и продвигает Multiply, поэтому веса по умолчанию такие:
- чаще всего: открытие позиций, Multiply, доливка залога (SPY с крана сразу идёт в работу), наращивание долга, депозит в Stability Pool, клейм наград
- изредка: закрытия, выводы и погашения, чтобы активность выглядела живой
- ставка 5–12%: выше средней по рынку, поэтому позиции реже попадают под редемпшен
- залоговое покрытие не опускается ниже 160% (минимум протокола 110%)

## Логи

| Файл | Содержимое |
|---|---|
| `logs/florin.log` | то же, что в консоли |
| `logs/debug.log` | каждая tx (функция, аргументы, газ, nonce, hash, gasUsed), снапшоты балансов, выбор действий, ответы крана, полные трейсбеки |
| `logs/errors.log` | только предупреждения и ошибки |
| `logs/accounts/NN_0x….log` | история отдельного аккаунта |

## Правила протокола

- минимальный долг позиции: **1000 FUSD**; ставка 0.5–250%; MCR 110%
- при открытии позиции блокируется **0.001 ETH** (компенсация ликвидатору, возвращается при закрытии)
- пока рынок SPY на паузе (`isStockPaused`), нельзя открывать позиции, занимать больше и выводить залог; бот это учитывает
- RPC идёт напрямую: многие резидентные прокси блокируют `rpc.testnet.chain.robinhood.com`

## Структура

```
main.py              CLI и планировщик (потоки, сон, таймеры)
settings.py          основные настройки
config.py            все остальные настройки
florin/contracts.py  адреса контрактов и константы
florin/chain.py      RPC, отправка tx, EIP-2612 permit, расшифровка revert
florin/protocol.py   действия протокола (Borrow / Multiply / Earn / Manage)
florin/strategy.py   профили аккаунтов и логика сессии
florin/utils.py      логи, аккаунты, state, кран, менеджер прокси
```
